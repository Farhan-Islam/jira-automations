# Automation rules

This folder is for documenting your Jira automation rules. Each rule (or related group) can have its own file.

## How to add a rule

1. Create the rule in Jira (Space, More actions, Space settings, Automation).
2. Create a new file here (e.g. assign-on-triage.md) using the rule template in templates/rule-template.md.
3. Commit the file so the rule is versioned and searchable.
